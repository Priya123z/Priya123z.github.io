Rate limited? Use your own key

The shared key is on a free tier with a daily budget, so it is capped per visitor. A free Groq key from console.groq.com/keys removes the cap. It is sent with the request and never stored.

Behind this: Groq first, OpenRouter if Groq is busy, and a saved example if both are out of budget — labelled as such rather than pretending to be live. Requests are budgeted by token count, because tokens per minute runs out before request count does. Source ↗
