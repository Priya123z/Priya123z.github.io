About

★ Flagship · AI

aiqa — AI QA Copilot for CI/CD

A drop-in pipeline that reviews code on every push with an LLM, surfaces real defects and reliability risks, generates the missing Gherkin + Pytest tests, and publishes a shareable HTML report — with a weighted risk score and a pass/fail quality gate. Runs in GitHub Actions. Free to run on any OpenRouter model. This is the productized version of the AI-in-testing direction on my résumé.

OpenRouter LLM Python 3.11 Pydantic v2 Pytest Jinja2 GitHub Actions
  • Reviews each file with cross-file context (RAG-lite) — catches integration bugs like "payments never verifies the token auth issues"
  • Generates real tests (.feature + pytest) and self-heals broken selectors into resilient Playwright locators
  • Every LLM response is validated through Pydantic before it reaches a report — no fabricated findings
  • Weighted risk_score + gate; 18-test suite runs green with no API key (LLM mocked)
  • A real run on a 3-file demo API surfaced 21 findings (5 critical) — the live report is that run, not a screenshot
